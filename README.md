# ✅ To-Do App

A desktop To-Do List application built with Python and Tkinter that helps users manage daily tasks with persistent JSON storage.

## 🚀 Features

- ➕ Add tasks
- ✔ Mark tasks as completed
- 🗑 Delete tasks
- 💾 Automatic JSON storage
- 🖥️ User-friendly graphical interface

## 🛠️ Technologies Used

- Python
- Tkinter
- JSON

## 📁 Project Structure

```
ToDo-App/
├── main.py
├── tasks.json
├── requirements.txt
├── .gitignore
├── LICENSE

```

## ▶️ Run the Project

```bash
python main.py
```
